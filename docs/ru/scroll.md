# Прокрутить и сохранить позицию просмотра {#scroll-ru}

[Английская версия](../scroll.md)

Используйте [ScrollState](../../include/portals/scroll.hpp). Каждый список и таблица хранит собственную логическую строку и дробный остаток. Этот фрагмент поддерживает колесо и клавиатуру. Уменьшите терминал, чтобы сократить видимую область. F10 закрывает приложение.

Фрагмент предполагает подключение `<portals/ui.hpp>` и `using namespace portals`; он использует адаптер Names — неизменяемый `ModelSnapshot<std::string>` с тремя записями — и функцию displayText для создания GraphemeText. Адаптер, функция, заголовки и вся программа приведены ниже и в [guide_scroll.cpp](../examples/guide_scroll.cpp).

```cpp
int main() {
  auto scene = ui::scene([](ManagedScene &owner) {
    return owner.model<std::string>(std::make_shared<Names>())
      .transform([](auto model) {
        return ui::virtualList(model,
          [](const ModelRow<std::string> &row) {
            return displayText(row.value);
          });
      });
  });

  return scene
    | ui::onKey("F10", ui::quit)
    | ui::runApp();
}
```

<summary>Полная программа</summary>

```cpp
#include <portals/ui.hpp>
#include <array>
#include <stdexcept>

using namespace portals;

class Names final : public ModelSnapshot<std::string> {
public:
  Names() : ModelSnapshot(1, 3) {
  }

  ModelRows<std::string> read(RowRange range) const override {
    return {RangeState::READY,
      std::span(rows_).subspan(
        static_cast<std::size_t>(range.first),
        range.count),
      {}};
  }

private:
  const std::array<ModelRow<std::string>, 3> rows_{{
    {{1, 1}, "Ada"}, {{2, 1}, "Grace"}, {{3, 1}, "Margaret"}
  }};
};

GraphemeText displayText(std::string_view value) {
  auto result = GraphemeText::from(value);

  if (!result) {
    throw std::runtime_error("Invalid display text");
  }

  return std::move(*result);
}

int main() {
  auto scene = ui::scene([](ManagedScene &owner) {
    return owner.model<std::string>(std::make_shared<Names>())
      .transform([](auto model) {
        return ui::virtualList(model,
          [](const ModelRow<std::string> &row) {
            return displayText(row.value);
          });
      });
  });

  return scene
    | ui::onKey("F10", ui::quit)
    | ui::runApp();
}
```

</details>

[Исходник примера](../examples/guide_scroll.cpp). Добавьте исходник в C++23-проект и свяжите его с целью portals::core ([инструкция сборки](getting-started.md)). Запустите программу в терминале.

Живое представление сохраняет позицию между кадрами и при скрытии. Поставщик с ограниченным locateRow позволяет удерживать первую видимую запись при вставках. Перезапуск или пересоздание представления требует хранилища приложения. Автоматическое постоянное хранение позиции — TBD; срок не назначен.

## Восстановить позицию после пересоздания

Фрагмент выполняется на UI между кадрами. tree — живое дерево, list — его Node<VirtualList<std::string>>, savedRow — хранимое приложением значение uint64_t, reportError — обработчик ошибок приложения. Чтение выполняется до удаления старого списка, восстановление — после создания нового.

```cpp
auto saved = tree.read(list, [&](const VirtualList<std::string> &view) {
  savedRow = view.firstRow();
});

if (!saved) {
  reportError(saved.error());
}

// Later, after rebuilding list:
auto restored = setVirtualListFirst(tree, list, savedRow);

if (!restored) {
  reportError(restored.error());
}
```

Для таблицы используйте VirtualTable<T>::firstRow и setVirtualTableFirst. Следующая подготовка ограничит позицию новым числом строк. Целый setter сбрасывает дробный остаток и привязку к идентификатору. scrollState() возвращает копию с дробью, но общего setter для восстановления всей копии у представления нет: восстановление дроби и идентичности — TBD, срок не назначен. Формат файла и момент сохранения выбирает приложение; виджеты не выполняют ввод-вывод.

<details>
<summary>Справка API и ограничения</summary>

`ScrollState` из `<portals/scroll.hpp>` также хранится внутри `VirtualList<T>` и `VirtualTable<T>`. Изменения представлений выполняются через существующий UI-поток и планировщик.

**Дробная позиция**

Позиция в логических строках — пара `(rasterOffset(), fraction())`: точный индекс `uint64_t` и конечная доля `double` в `[0, 1)`. При растеризации позиция округляется вниз. Четыре шага по `0.25` продвигают на строку; шаг `-0.25` от строки 1 даёт строку 0 с долей `0.75`. Текст начинается на целых координатах ячеек; `row_height` переводит логические строки в строки ячеек. Доли сохраняют обычные ограничения двоичной арифметики. Остаток, округлённый до 1 при переносе, ограничивается ближайшим представимым числом ниже 1.

`ScrollState::moveBy(rows, count)` принимает конечное знаковое движение и ограничивает позицию строками 0 и `count - 1`. Избыточное движение за границей отбрасывается. Пустая модель сбрасывает обе части позиции. Целая часть не преобразуется в `double`, включая индексы выше 2^53. Неверные доли и нечисловое движение возвращают `TreeError::INVALID_ARGUMENT` без изменений. Тип не выделяет память и не вызывает обработчики; отдельный владелец синхронизирует изменения.

После первой успешной подготовки используйте `scrollVirtualList` или `scrollVirtualTable`, передавая движение в логических строках. Целочисленные события колеса используют тот же `ScrollState`; масштабирование аппаратных шагов задаёт адаптер ввода. Изменение одной доли без смены целой позиции не запрашивает рисование, не отменяет запросы, не читает провайдера и не форматирует строки. Смена целой позиции запрашивает рисование и требует новой подготовки через `prepareVirtualList` или `prepareVirtualTable`. Приложение обрабатывает запрос работы, возвращённый подготовкой. `setVirtualListFirst` и `setVirtualTableFirst` задают точный целый индекс, сбрасывают долю и прежнее намерение привязки к якорю.

**Стабильный якорь**

Провайдер может реализовать `ModelSnapshot<T>::locateRow(RowId)` через индекс идентичностей своего неизменяемого снимка, например хеш-таблицу или упорядоченный индекс. Работа в UI должна быть ограничена. Полное сканирование модели, загрузка данных, блокировка и чтение более нового снимка запрещены. Идентичность определяет полный `RowId`, включая поколение. Результат содержит одно из трёх состояний:

- `FOUND`: индекс принадлежит этому снимку и меньше числа его строк.
- `NOT_FOUND`: поиск поддерживается, но идентичность отсутствует.
- `UNSUPPORTED`: состояние по умолчанию для провайдеров без индекса идентичностей.

`ModelFrame<T>::locateRow` использует сохранённый базовый снимок, проверяет идентичности и границы результата. Нехватка памяти преобразуется в `NO_MEMORY`, другие исключения — в `CALLBACK_FAILED`. Метод не отправляет запросы и не запрашивает обновление интерфейса.

Первая готовая видимая строка становится якорем независимо от выделения. При новой ревизии провайдер с поддержкой поиска переносит её позицию до ограниченной подготовки диапазона. Вставка или удаление строк перед видимой областью сохраняет якорную строку и дробный остаток. Если сам якорь удалён, остаётся прежний индекс, ограниченный новой последней строкой; следующая первая готовая строка становится якорем. При `UNSUPPORTED` сохраняется поведение по порядковому индексу. Ошибка поиска или форматирования сохраняет прежнее подготовленное представление.

`ensureVirtualListVisible(tree, list, pin, id)` и `ensureVirtualTableVisible(tree, table, pin, id)` получают тот же общий снимок кадра, который будет использовать следующая подготовка. Результат различает все три состояния поиска. При `FOUND` позиция минимально сдвигается по последней подготовленной видимой области; запрашивается рисование и отменяется прежняя работа диапазона. Выделение сохраняется. Фиксированный заголовок таблицы не входит во вместимость тела. Строка выше непустой видимой области показывается начиная с первой ячейки. Область нулевой высоты показать строку не может.

Затем повторите подготовку, обработайте возвращённую работу при необходимости и рисуйте соседние представления с тем же снимком кадра. До первой подготовки прокрутка и показ строки возвращают `WOULD_BLOCK`. Чужой снимок модели и устаревший узел отклоняются через проверяемые дескрипторы. Читайте значения через `tree.read`; изменяйте их только в UI-потоке вне `tree.frame`. Заимствованные строки и указатели виджетов из этих операций не выходят.

**Скрытые области**

Скрытие предка освобождает подготовленные строки списка и таблицы и отменяет их запросы диапазонов. Якорь и выделение сохраняются. Публикации модели продолжаются через планировщик. После показа представление готовит актуальный общий снимок кадра и переносит якорь. Подготовка скрытого представления не читает провайдера и не форматирует строки.

`WidgetTree::paint` пропускает виджет при скрытом предке или корректной геометрии с пустым отсечением; его метод рисования не вызывается. Некорректная геометрия возвращает `INVALID_GEOMETRY`. Публикации модели и жизненный цикл компоновки и подготовки продолжаются. Представления могут запрашивать дополнительные строки за видимой областью, но форматируют только видимые логические строки.

</details>
