# Кнопки {#button-guide-ru}

[English version](../button.md) · [Галерея контролов](widget-gallery.md) · [Общие действия](actions.md)

`ui::button` вызывает действие по Enter, Space или нажатию левой кнопки мыши.
Для постоянного логического значения используйте checkbox или switch.
Отключённая кнопка не выполняет действие. Обычная кнопка рисует контур из скобок;
`ui::plainButton` сохраняет поведение, но рисует только подпись.

## Полная программа

Кнопка добавляет в поле текста одно отменяемое изменение. F10 закрывает сцену.
Runner сообщает ошибки и восстанавливает терминал; пример не содержит парсера
CLI или воспроизведения терминальных событий.

\include click_handlers/main.cpp

Соберите цель `portals_click_handlers` с `PORTALS_BUILD_EXAMPLES=ON`. Подключение
установленного SDK описано в [руководстве по пакету](package.md).
Кнопки в [форме заметки](first-application.md) выглядят так; изображение показывает
эту более полную форму, а не минимальную программу выше:

![Кнопки в форме заметки](images/first-application.png)

## События и текст

Сохраните `ui::Ref<Button>`, чтобы позже добавить `ui::onClick` или изменить текст.
`button.text() = "Save"` меняет подпись через механизм диагностики сцены.
`ui::onClick(ref, handler)` принимает обработчик без аргументов или с параметрами
клика; несколько обработчиков вызываются по порядку регистрации, пока один не
остановит дальнейшие вызовы через `params.stop()`. См.
[обработчики клика](declarative-ui.md#pipe-click-handlers-ru).
Для команды, общей с меню и клавишами, используйте [actions](actions.md).

## Настройка оформления {#button-styling-reference-ru}

Естественный тип — `Button`; `.id("save")` или класс уточняет селектор.
Отрисовываются normal, focused и disabled, причём disabled имеет приоритет.
Checked в метаданных действия не вводит состояние отрисовки `:selected`;
псевдосостояния `:hover` нет. Ручной `ControlStyle` до темы использует цвета
терминала, полужирный фокус и курсив отключённой кнопки. Тема и приложение
переопределяют отдельные поля; пропущенные поля сохраняют результат нижнего слоя.

| Свойство | Значения / результат |
|---|---|
| `foreground`, `background` | `#RRGGBB`; подпись, контур и поверхность используют общий вычисленный стиль |
| `bold`, `italic`, `underline` | `true` или `false`; явное false снимает атрибут нижнего слоя |
| `width`, `height` | Ячейки, `auto`, `fit-content`, `flex(положительный вес)` в runtime PSS |
| `min-width`, `max-width`, `min-height`, `max-height` | Неотрицательные жёсткие границы в ячейках; runtime PSS, compile-time поддерживает только min-width |

Размеры нельзя задавать селектором с состоянием или read-only. Противоречие точного
размера и жёстких границ отклоняет обновление с сохранением прежнего стиля/геометрии;
см. [политики размеров](layout.md). Широкая кнопка центрирует подпись между скобками
на краях выделенного прямоугольника; высота не центрирует однострочную подпись
по вертикали. Отдельных свойств PSS для строк скобок, скругления и разных цветов
контура/подписи нет. Другой контур даёт `ui::plainButton` внутри
[оформленной рамки](compact-primitives.md#primitives-styling-reference-ru).
Рамка независима от обычных скобок кнопки.

```pss
Button#save { width: fit-content; min-width: 12; bold: true; }
Button#save:focused { foreground: #ffffff; background: #245070; }
Button#save:disabled { foreground: #7d828c; italic: false; }
```

Примените правила через `ui::style(...)` или `ui::styleFile(...)`, задав кнопке
ID save в рецепте или загруженной сцене. [Каскад](styling-guide.md) объясняет
приоритет темы/слоёв/селекторов; [базовые контролы](controls.md#basic-controls-styling-reference-ru)
описывают общие ручные значения. Оформление не меняет активацию и не делает
кнопку read-only.
