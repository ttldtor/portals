## Параметры стилей

<a id="planned-style-parameters-ru"></a>

**TBD — M5:** типизированные параметры, выражения, диагностика источников и
обновление зависимостей. Источники стилей через `Ref` — **TBD — M1**.

| Предложенная форма | Значение |
|---|---|
| `$name` | Типизированное значение, переданное или наблюдаемое из кода приложения |
| `theme.text` | Семантический параметр активной темы |
| `this.text` | Разрешённое свойство текущего контрола |

Имена разрешаются в своих пространствах. Подстановку `theme.text` при отсутствии
`$text` нужно задать явно. Перед `theme` и `this` знак доллара не нужен.

Предложенный синтаксис PSS — **TBD — M5**:

```css
/* Proposed syntax; runtime PSS v0 does not accept it. */
Button {
  foreground: $text;
  background: theme.surface;
  min-width: len(this.text) + 2;
}
```

`this.text` содержит отформатированный локализованный текст. `len` в выражениях
размера измеряет ячейки терминала с `WidthPolicy` компоновки. Смена языка
и аргументов текста требует пересчёта зависимых измерений. Обычные кнопки сохраняют
естественный размер; формулы настраивают ограничения. Рамку и отступы учитывают
один раз. База, диапазон и округление процентов ещё не определены.
Поддержка единиц CSS `px`, `em`, `vh` и `vw` не согласована.

### Обновление параметров

Предложенный API — **TBD — M5**; возвращаемый тип и перегрузка с явным результатом
ещё не определены:

```cpp
// Proposed API; not currently compilable.
ui::currentScene.setParam("width", value);
```

Присваивание должно проверить всех затронутых потребителей значения до атомарного
обновления. При отказе движок сохраняет параметры и вычисленные стили и сообщает
типизированную ошибку. Изменения внешних свойств, моделей и побочные эффекты
обработчика остаются ответственностью вызывающего кода.

Параметры относятся к верхнему контексту переопределений сцены, где доступны
значения темы. Явные переопределения сохраняются при смене темы; затронутые
зависимости пересчитываются. Присваивание обновляет выражения, использующие параметр.
Согласование с `USER` — **TBD — M5**; приоритеты каскада сохраняются.
`currentScene` ограничена допустимым контекстом и не должна удерживать глобальную
владеющую сцену или обращаться к предыдущей сцене вне этого контекста.

Явно выбранная необязательная политика может передать неприменимое значение
следующему подходящему объявлению нижнего приоритета или значению по умолчанию.
Применимость проверяется для каждого потребителя. Политика по умолчанию сообщает
об отсутствующих параметрах и отклоняет присваивание неизвестным именам.
Ошибки синтаксиса, неизвестные функции и поля, нехватка памяти, чужой поток,
закрытая сцена и ошибки жизненного цикла сохраняются при любой политике.

`ui::Params`, `ui::params`, обновляемый по уведомлениям `ui::bind(source, transform)`,
`??` и `grayScale` — варианты записи для обсуждения, **TBD — M5**.
Для наблюдения за захваченными переменными C++ нужны уведомления свойств или моделей.
Обновления доставляются в UI-поток с учётом очистки сцены; типизированные значения
остаются данными. Цвета запрашивают PAINT, размеры — LAYOUT; равный результат
не требует дополнительной перерисовки. Существующие экспериментальные параметры
C++ и `mix` описаны в [стилях времени компиляции](compile-time-styles.md).

## Темы

<a id="planned-themes-ru"></a>

**TBD — M5:** единым редактируемым источником встроенных тем станет PSS.
Из него будут создаваться C++-представления и встроенные ресурсы, чтобы приложению
не требовались файлы тем в рабочем каталоге. В текущей версии доступны существующие фабрики.

Загрузка темы будет проверять таблицу и атомарно заменять `THEME`, сохраняя
`APPLICATION` и `USER`. Используется существующий механизм стилей.
Общие правила контролов и состояний получат типизированные семантические параметры
с полными светлыми и тёмными значениями по умолчанию. Темы смогут переопределять
параметры и правила. Контракт и отдельный срок автоматического определения
системного светлого/тёмного режима пока не установлены.

```text
PSS -> встроенный ресурс или файл -> проверка -> замена THEME
внешняя тема -> импортёр -> нормализованный PSS ---^
```

### Внешние форматы

Импортёры — **TBD**; отдельный майлстоун и оценка объёма работы ещё не назначены.
Они будут преобразовывать поддерживаемые поля в параметры и правила PSS.
Разбор внешних форматов останется за пределами обязательных зависимостей ядра.
Импорт темы, записанной кодом, не должен выполнять этот код.

Первыми предложены цветовые схемы Windows Terminal JSON и Base16/Tinted YAML.
Для каждого импортёра нужны версия формата, соответствие полей, значения
по умолчанию, описание неподдерживаемых полей и сведения об источнике и лицензии.
ANSI-палитры требуют явного настраиваемого соответствия ролям контролов,
выделению, ошибкам и предметным цветам, например bid/ask.

Выражения PSS остаются **TBD — M5**. Существующий типизированный `LiveThemeRef`
требует явных обновлений в UI-потоке при изменениях свойств предметной области.
