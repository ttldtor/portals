# Загрузка сцен из текста и файлов {#scene-loading-guide-ru}

**TBD — M1 / U84**, после поиска именованных ссылок U126 и применения стилей через Ref U127. Этот загрузчик времени выполнения запланирован. Сейчас описания сцен создаются на C++; [сцены времени компиляции (EN)](../compile-time-scenes.md) — это структуры C++ с вычислением во время компиляции, а не парсер внешнего файла сцены. [Английский оригинал](../scene-loading-guide.md).

Не путайте файл таблицы стилей с файлом сцены. Существующая конструкция `scene | ui::style(ui::file(path))` загружает объявления PSS в сцену; она не создаёт элементы управления и не связывает действия из файла.

## Границы планируемого загрузчика

Утверждённое направление: ввод из текста/файла, типизированный реестр с явным списком разрешённых элементов, именованные ссылки и существующее разрешение элементов управления/i18n. Загрузчик использует текущую среду выполнения сцены. Общие выражения стилей времени выполнения — отдельный пакет **TBD — M5 / U128**, они не являются предпосылкой для первой версии загрузчика.

## Справка по синтаксису

**TBD — проектное ревью U84.** Конкретная грамматика сцены, типы значений свойств, допустимая вложенность, позиции в исходнике и синтаксис регистрации действий/моделей ещё не являются реализованным контрактом. Не копируйте примеры из этого раздела как работающий код, пока контракт не будет утверждён и реализован.

В руководстве будут определены:

- Текстовый ввод и нативные пути к файлам, кодировка и метки источника.
- Объявления элементов управления и компоновки, идентификаторы и поиск ссылок.
- Допустимые типы свойств и явное разрешение ресурсов/i18n.
- Подключение именованных действий/моделей, переданных кодом приложения на C++.
- Неизвестные элементы управления/свойства, недопустимые значения и повторяющиеся идентификаторы.
- Владение, ограничения размера/глубины, атомарный отказ и очистка.
- Ошибки файлов и точная политика перезагрузки; автоматическое наблюдение за файлами не предполагается.

## Планируемые примеры

Все три примера имеют статус **TBD — U84**; окончательная интеграция в кулинарную книгу запланирована на M7/U96:

1. Одна метка и одна кнопка, загруженные из строки сцены в памяти.
2. Файл формы с именованными ссылками, действиями приложения и PSS.
3. Целостная форма с привязкой модели, i18n и проверенной обработкой некорректного файла.

Пока используйте [декларативную композицию на C++ (EN)](../declarative-ui.md) и существующие [запускаемые примеры (EN)](../examples.md). Их синтаксис уже входит в библиотеку.
