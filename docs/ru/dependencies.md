## Требования к сборке

Для сборки Portals из исходников нужны CMake 3.24+ и инструментарий с поддержкой
C99 и C++23, включая `<expected>` и `<format>` в стандартной библиотеке C++.
Команды руководства используют Ninja. Для загрузки через Git в FetchContent
нужен Git. Все зависимости из таблицы уже находятся в исходниках Portals;
при их сборке дополнительная загрузка зависимостей не выполняется.

В CMake-проекте своего приложения можно указать `LANGUAGES CXX`. Portals включает
C в собственной поддиректории, чтобы собрать utf8proc как C99. Компиляторы
обоих языков должны быть доступны в выбранном инструментарии. Установленный
SDK уже содержит архивы библиотек, поэтому при подключении его к приложению
C++ компилировать исходники C не требуется.

`portals::core` задаёт публичные пути к заголовкам, требование C++23 и зависимости
статической компоновки. На UNIX также подключается системная цель Threads.
Совместимость компилятора, архитектуры и среды выполнения описана в
[подключении пакета](package.md). Сведения об исходниках по ссылкам выше
указывают закреплённые версии и ревизии. Для utf8proc, Boost.PFR, doctest
и тестовых данных Unicode также сохранены манифесты файлов. CMake проверяет
их контрольные суммы при конфигурации соответствующих компонентов сборки.

## Инструменты справки

Для генерации HTML-справки нужны Doxygen 1.18 или новее и Mermaid CLI.
Проверенный инструментарий диаграмм — Node.js 24 LTS и Mermaid CLI 12.
Эти инструменты не нужны для сборки обычного приложения на Portals и чтения
готовой HTML-справки. Установка описана в
[сборке Portals и примеров](getting-started.md).

При стандартной структуре установки SDK тексты лицензий находятся в
`share/Portals`. HTML-справка содержит тексты лицензий, на которые ссылается
эта страница, для чтения без сети. Структура установки и поставки описана в
[составе пакета](package.md).
