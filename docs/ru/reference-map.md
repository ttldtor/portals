## Справка по API

Подробная справка C++ API общая и доступна только на английском. Идентификаторы
API и комментарии в исходниках сохраняют исходный язык; русские руководства
ссылаются на тот же справочник.

В сгенерированной HTML-справке раздел **API reference** содержит типы, концепты,
пространства имён, члены типов и заголовки. Например, ссылки
[ui::Scene](../../include/portals/ui_scene.hpp) и [WidgetTree](../../include/portals/widget.hpp)
ведут к контрактам типов в HTML и к публичным заголовкам в репозитории.
Для обычного приложения начните с `ui.hpp`, `managed.hpp` и `application.hpp`.

Экспериментальные варианты имеют отдельные контракты:
[сцены времени компиляции](compile-time-scenes.md), [типизированные стили времени компиляции](compile-time-styles.md)
и [PSS времени компиляции](compile-time-pss.md). Декларативную композицию и PSS
времени выполнения можно использовать без этих вариантов.

## Чтение на GitHub и в HTML

Относительные Markdown-ссылки работают в рабочей копии и на GitHub. Разделы
с полными примерами содержат ссылки на настоящие исходники. Команды Doxygen
`\include` разворачиваются в нумерованные листинги в HTML; на GitHub используйте
сопровождающую ссылку на исходник. Метки вида `{#examples}` — идентификаторы Doxygen.

Markdown описывает выбранную ветку исходников. [Опубликованная HTML-справка](https://ttldtor.github.io/portals/)
соответствует последнему стабильному релизу; проверки PR создают артефакт предпросмотра.
HTML добавляет к тем же руководствам дерево навигации, поиск и ссылки на API.
Сгенерированный каталог также работает без сети. Языковые ссылки вверху каждой
переведённой страницы ведут на ту же тему. Пометка **English** обозначает материал,
у которого пока нет русского перевода. Исходные редакции и порядок обновления
описаны в [сопровождении переводов](development.md#documentation-translations-ru).
