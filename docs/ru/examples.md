# Запускаемые примеры {#examples-ru}

[Подробная английская версия](../examples.md)

Соберите проект с `PORTALS_BUILD_EXAMPLES=ON`.
Программы gallery, dashboard, replay и custom widget используют общий
[цикл приложения](application.md) и конечный режим `--check` для проверки в памяти.
Его результат проверяет логику; внешний вид и восстановление системного терминала
проверяются отдельно.

| Программа | Что попробовать |
| --- | --- |
| portals_click_handlers | Минимальный пример с оператором `|`: Add Hello добавляет текст, F10 завершает |
| portals_gallery | Tab переключает фокус между редактором, CheckBox и кнопками действия и выхода, Enter подтверждает, F2 меняет одну из шести тем |
| portals_dashboard | Таблица и свечной график одной модели; --stress добавляет состояние диагностики |
| portals_custom_widget | Собственный Meter: Left/Right меняют уровень, F2 меняет тему |
| portals_replay_example | Dashboard с записанной лентой цен по умолчанию |
| portals_editor_history | Три режима подтверждения текста и Undo/Redo; [описание](editor-history-demo.md) |

F10 завершает интерактивные примеры; gallery/dashboard/custom widget также
принимают Ctrl+C. Мышь работает в пределах возможностей терминала.
Обработчиков системных сигналов примеры не устанавливают; принудительное
завершение процесса находится за пределами штатной очистки.

## Галерея и собственный виджет

```text
portals_gallery --theme nord
portals_custom_widget --theme catppuccin-latte
portals_gallery --check --theme gruvbox --ansi16
```

Оба принимают `--theme NAME`, `--ansi16`, `--check`, `--help`.
Имена: modern по умолчанию, turbo, nord, gruvbox, tokyo-night, catppuccin-latte.
F2 проходит их по кругу. ANSI16 меняет реальное кодирование на 16 цветов;
их вид задаёт палитра терминала. Дополнительно gallery принимает конечные
режимы initial, keyboard, mouse и disabled. Интерактивная gallery::FluentForm
владеет сценой; её примерный take преобразует ошибку подготовки в общее исключение.
Для точных причин используйте проверяемые результаты библиотеки.
--check проигрывает конечный сценарий ввода и изменения размера
в памяти; --help выводит параметры без запуска. Ошибочный параметр или тема
дают код 2, ошибка выполнения после попытки восстановления — 1, успех — 0.

## Dashboard

```text
portals_dashboard --rate 10000 --fps 30 --rows 1000000 --seed 42
portals_dashboard --rate 0 --delay-ms 250 --ansi16 --ascii
portals_dashboard --mode replay --trace trace.json --duration-ms 5000
portals_dashboard --check --mode replay --delay-ms 250
portals_dashboard --stress --rate 10000 --rows 1000000
```

Настройки загрузки:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| --page-rows N | 256 | Логических строк на страницу |
| --cache-pages N | 8 | Записей доступности, включая начальную страницу и ожидающие |
| --cache-bytes N | 262144 | Бюджет данных строк одного снимка, байты |
| --load-jobs N | 4 | Одновременных отложенных загрузок |
| --prefetch-pages N | 1 | Соседних страниц по направлению; 0 выключает |

Логическое число инструментов может достигать 1000000000 без виджета на строку.
--seed управляет синтетической лентой; --mode synthetic|replay выбирает источник.
Replay циклически повторяет 16 встроенных цен из examples/replay/data.hpp.
Файлы текущего каталога и сеть ему не нужны.

--delay-ms задерживает получение некешированной страницы на 0..60000 мс;
первая доступна сразу. Навигация внутри полезной страницы сохраняет срок
загрузки при замене запроса. Пропуск кеша показывает заменители загружаемых строк;
таблица и график имеют независимые запросы и общую ограниченную доступность.
Размеры положительны и должны помещаться в size_t. Недостаточная комбинация
бюджетов отклоняется при подготовке; слишком большая область просмотра даёт ошибку получения диапазона.
Ограничение в байтах учитывает полную страницу ModelRow<Quote>, включая последнюю неполную;
накладные расходы аллокатора и старые снимки не входят. Запрошенные строки загружаются раньше предположительно нужных соседних страниц.

Поставщик кеширует доступность стабильных инструментов. Значения заново
порождаются из агрегата рынка каждой ревизии. Готовность публикуется также
при --rate 0; повторных публикаций готовой страницы нет. --check выводит
попадания/пропуски, полезные/отменённые задачи и максимумы страниц/задач/байтов.

--pump-budget: 1..10000 тиков на вызов, по умолчанию 512. Каждый сгенерированный
тик агрегируется в OHLC; объединяются только снимки отображения. Опоздавший
таймер продолжает со следующего несгенерированного номера ограниченными
вызовами. ticks и запланированные тики различаются; stop отменяет оставшиеся.
Поставщик работает на UI. Заданная частота описывает расписание; производительность измеряется отдельно.

Таблица и свечи используют один закреплённый снимок на кадр, включая повторные проходы.
Готовятся видимые строки плюс две запасные с каждой стороны. Инструменты делят
OHLC с детерминированным смещением цены. --ascii выбирает ASCII-подписи и свечи;
--ansi16 — реальное кодирование цветов. По умолчанию свечи используют
одноячеечные Unicode-фитили. Темы Modern/Turbo встроены типизированно и
соответствуют PSS; цвета роста/падения остаются различимыми.

Tab меняет фокус; стрелки/Home/End управляют таблицей; Enter подтверждает заметку;
F2 переключает Modern/Turbo. Inspect присваивает заметке её значение.
Для наблюдения этого действия используйте --rate 0 --trace trace.json.
Трасса различает handler_returned, value_unchanged и frame_not_requested;
значения текста/VT не экспортируются. Ошибки файла сообщаются после восстановления.
--duration-ms до 3600000 останавливает при следующем обслуживании поставщика;
0 сохраняет интерактивный режим. Зависание терминального приложения или вывода может продлить очистку.
--check проигрывает одну логическую секунду и печатает статистику после close.

## Где читать исходники

[gallery/form.hpp](../../examples/gallery/form.hpp) показывает владеющую форму,
стандартные привязки и сценовые команды. [meter.hpp](../../examples/custom_widget/meter.hpp)
показывает собственный final-виджет и onPrepare перед рисованием.
[dashboard.hpp](../../examples/dashboard/dashboard.hpp) показывает общую модель
и виртуальные представления, размер которых определяет Grid.

Регистрация подготовки таблицы перед графиком позволяет графику прочитать
её первую строку. Обработчики получают общий заимствованный снимок и копируют
запросы в ограниченные слоты поставщика. pendingLatest очищается после принятия
издателем. Поставщик владеет таймером и управляет отменой, повторами и предварительной загрузкой.
При `stop` таймер отменяется перед закрытием управляемого поддерева и модели.
ingressObserver измеряет задержку только входа снимков, с внешним ограниченным
хранилищем. tickCount/scheduledTicks/pendingTicks/stoppedAt показывают реальный
ход генерации.

## Минимальная программа

[click_handlers/main.cpp](../../examples/click_handlers/main.cpp) использует
`ui::Ref<T>`, строковые стили и обработчики, добавленные оператором `|`. В нём нет CLI и --check; сцена владеет
контролами, Ref наблюдают их. runApp сообщает типизированные ошибки подготовки и выполнения
после очистки. Подробности [параметров и времени жизни](declarative-ui.md#pipe-click-handlers-ru).
Полная форма с list/table/chart — [composed_named.cpp](../../tests/package_consumer/composed_named.cpp).
