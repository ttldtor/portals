# Глоссарий {#glossary-ru}

[Английский оригинал](../glossary.md).

| Термин | Значение в Portals | Читайте дальше |
|---|---|---|
| Описание / рецепт (Description / recipe) | Владеющее значение однократного использования, описывающее создаваемые элементы управления; это ещё не смонтированный виджет | [Декларативный UI (EN)](../declarative-ui.md) |
| Сцена (Scene) | Фасад `ui::Scene` для рецепта, настройки, запуска и очистки | [Декларативный UI (EN)](../declarative-ui.md) |
| ManagedScene | Регистрации, свойства и модели во владении сцены поверх существующих Application/дерева | [Управляемые элементы (EN)](../managed-controls.md) |
| Ref | Наблюдающий типизированный дескриптор; его копирование не продлевает жизнь сцены или виджета | [Текстовые свойства (EN)](../text-property.md) |
| Node | Проверяемая идентичность узла со слотом и поколением; наблюдает за смонтированным виджетом | [Дерево виджетов (EN)](../widget-tree.md) |
| Property | UI-владеющее типизированное значение, публикующее неизменяемые снимки | [Свойства (EN)](../property.md) |
| ManagedState | Слабый дескриптор свойства, которым владеет сцена | [Управляемые элементы (EN)](../managed-controls.md) |
| Snapshot | Владеющее неизменяемое значение/ревизия, сохраняющееся независимо от последующих обновлений | [Свойства (EN)](../property.md) |
| Binding | Явная связь между моделью/состоянием и представлением; обычное присваивание текста копирует значение | [Руководство по привязкам](bindings-guide.md) |
| PSS | Синтаксис таблиц стилей Portals; напоминает CSS, но имеет собственную компактную грамматику | [Руководство по стилям](styling-guide.md) |
| Theme | Палитра, заданная обычными правилами стилей и установленная в слое THEME | [Руководство по темам](themes-guide.md) |
| Токен темы (Theme token) | Именованное значение палитры; типизированные параметры темы отличаются от неподдерживаемых строковых переменных PSS | [Руководство по темам](themes-guide.md) |
| LiveTheme | Контроллер типизированных параметров, пересчитывающий обычные таблицы стилей с помощью существующего resolver | [Стили времени компиляции](compile-time-styles.md) |
| Слой / уровень приоритета (Layer / tier) | Независимо установленная таблица стилей / класс её приоритета | [Слои стилей](style-layers.md) |
| Селектор (Selector) | Условие по явным метаданным типа, идентификатора, классов и состояния | [Стили (EN)](../styles.md) |
| Инвалидация (Invalidation) | Запрос пересчитать компоновку или отрисовку; компоновка включает отрисовку | [Свойства (EN)](../property.md) |
| Поток-владелец UI (UI owner thread) | Поток, в котором разрешены изменение сцены/дерева и операции жизненного цикла | [Управляемые элементы (EN)](../managed-controls.md) |
| Диагностика / итоговый отчёт (Diagnostic / final report) | Запись операции / отчёт, передаваемый после попытки очистки | [Декларативный UI (EN)](../declarative-ui.md) |
| `$name` | **TBD — M5/U65/U128:** параметр из кода или наблюдаемого источника; не автоматический псевдоним параметра темы | [Темы](themes-guide.md) |
| `theme.*` | **TBD — M5/U65/U128:** пространство имён семантических параметров PSS-темы | [Темы](themes-guide.md) |
| `this.text` / `len` | **TBD — M5/U128:** локализованный текст контрола / его ширина в терминальных ячейках согласно WidthPolicy, не байты | [Стили](styling-guide.md) |
| Checked назначение параметра | **TBD — M5/U65/U128:** проверка candidate до атомарной публикации; optional-политика только явно | [Темы](themes-guide.md) |
| TBD | Запланированное поведение или незавершённый раздел руководства; сверяйтесь с таблицей майлстоунов/задач, не додумывайте синтаксис | [Содержание руководств](guides.md) |
| Майлстоун (Milestone) | Запланированная группа/порядок работ, а не обещанная календарная дата выпуска | [Содержание руководств](guides.md) |

Эти определения описывают контракты Portals, а не GUI-фреймворков вообще.
